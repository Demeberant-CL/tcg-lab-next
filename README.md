# TCG LAB NEXT

App Android (Kotlin + Jetpack Compose) para gestionar colección y mazos de **Pokémon TCG Pocket**.

## Estado

- Fase 0 (hotfix): permiso INTERNET + Gradle Wrapper ✅
- Fase 1 (estabilidad): reglas de mazo por nombre, updates atómicos, grilla completa, BD singleton ✅ (en curso)

## Compilar

```bash
./gradlew assembleDebug
```

## Aviso legal

App fan no oficial. Pokémon, Pokémon TCG Pocket y las marcas asociadas son propiedad de Nintendo / Creatures / GAME FREAK. Las imágenes de cartas son de terceros.
